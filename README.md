# Kombinat Elektrosvyaz No.4

A static parody website for the "official internet representation" of a fictional Soviet-era telecommunications equipment plant, OAO «Kombinat Elektrosvyaz No.4» (Sverdlovsk Oblast, est. 1961) — styled as a late-1990s corporate homepage, complete with retro web gimmicks.

## Features

- **Dial-up splash screen** — simulated modem handshake sequence on first visit (skippable, remembered per session via `sessionStorage`)
- **Visitor counter** — old-school incrementing digit counter (`localStorage`)
- **Fax order form** — a mock "send by fax" order flow with a fake sending/confirmation state

## Structure

- `index.html` — page markup and content
- `style.css` — styling
- `script.js` — dial-up splash, visitor counter, and fax form behavior
- `images/` — photos and illustrations
- `favicon*.png/svg`, `apple-touch-icon.png` — site icons
